# 圣合丰 SHENGHEFENG — Logo（木脚版）

原 logo 中间的支脚看上去像**金属脚**。本次改版在**完全不改动 SHENGHEFENG 字标和 圣合丰 书法**的前提下，
把中间的支脚重做成一眼可辨的**沙发实木脚**。

## 为什么原来像金属

| 原设计 | 观感 |
|---|---|
| 近黑色 `#3F1A08`，无材质 | 哑光金属 / 铁艺 |
| 又细又长、近乎平行的杆身（宽 56 → 25，长 165） | 铝合金挤压型材 |
| 杆身上的三条竖向凹槽 | 型材凹槽 |
| 针尖式收尾 | 金属脚钉 |
| 上方又薄又宽的平板 | 金属安装底板 |

## 改了什么

1. **颜色**：胡桃木／橡木暖色渐变，带圆柱受光，代替近黑色。
2. **木纹**：纵向顺纹 + 中部「大教堂纹」（弦切板的典型花纹）。
3. **型体**：上方实木方块 → 车削凸环（collar bead）→ 2.4:1 直锥身 → 车削脚圈 → 平底。
4. **比例**：宽 104 × 长 277（原 56 × 165），加粗加长，符合实木脚的敦实感。
5. **收尾**：平底带倒角，代替针尖，实木脚都是平底装脚垫的。
6. 竖向凹槽去掉，换成木纹。

字标 SHENGHEFENG 的字形、弧线排列、书法「圣合丰」、英文标语均**零改动**，
只因支脚变长，下方文字整体下移 99px 以保持留白平衡。

## 文件

| 文件 | 用途 |
|---|---|
| `shenghefeng-logo-wood.svg / .png / @2x.png` | 主用版，全彩木纹，白底 |
| `shenghefeng-logo-wood-transparent.svg / .png / @2x.png` | 同上，透明底 |
| `shenghefeng-logo-wood-1color.svg / .png / @2x.png` | 单色版，用于丝印、烫金、刺绣、传真、单色印刷 |
| `shenghefeng-mark-wood.svg / .png / @2x.png` | 只有图形标志，无中英文，透明底 |
| `comparison.png` | 改版前后对比 |
| `source-original.png` | 原始 logo，供追溯 |
| `build_logo.py` | 生成脚本，改颜色或比例改这个文件重跑即可 |

SVG 全部为**真矢量**（字标与书法经 potrace 描摹为路径，支脚为参数化路径），可无损放大用于大幅喷绘。

## 重新生成

```bash
pip install pillow numpy cairosvg
apt-get install -y potrace
python3 build_logo.py
```

## 小尺寸表现

110px 以上木纹清晰；110px 以下木纹淡化，但锥形轮廓、脚圈与平底仍能读出实木脚。
需要做 favicon 一类极小尺寸时，建议用单色版。
