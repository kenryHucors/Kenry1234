# Canva 使用说明

## 先看这一条：免费版 Canva 传不了 SVG

| 你的 Canva 版本 | 用哪个文件 |
|---|---|
| **免费版** | 用 `.png`。SVG 上传是 Pro 功能，免费账号传上去会报错 |
| **Pro / 团队版** | 优先用 `.svg`，放多大都不糊，还能在 Canva 里直接换颜色 |

## 文件选哪个

| 文件 | 什么时候用 |
|---|---|
| `logo-wood-colour-compact` | **最常用**。全彩木纹，透明底，不含最底下那行 CHINA / WORLDWIDE SUPPLY，没有多余空白，拖进去就能用 |
| `logo-wood-colour` | 完整版，含底部那行小字。注意这行字离主体很远，图会又高又窄 |
| `logo-wood-colour-whitebg` | 白底方图 1:1。用于头像、朋友圈、产品主图 |
| `logo-wood-1colour-compact` | 单色版。丝印、烫金、刺绣、纸箱唛头、传真 |
| `logo-1colour-recolourable-compact` | **要在 Canva 里换颜色就用这个**，见下 |
| `mark-wood-colour` | 只有木脚图形，没有文字。做水印、角标、包装花纹 |

## 在 Canva 里换整体颜色

普通单色版的木纹是白色线条画上去的，Canva 换色时木纹不会跟着变。
`logo-1colour-recolourable` 这两个文件不一样，木纹是**真的镂空**，整个 logo 是一个颜色。

操作：上传 SVG → 点中图形 → 左上角出现色块 → 选任意颜色，木纹会自动跟着走。
深色背景上就选米白 `#F5EFE6`，浅色背景上用品牌棕 `#3F1A08`。

（这个功能需要 Canva Pro，因为要传 SVG。）

## 上传步骤

1. Canva 左侧 **上传 Uploads** → **上传文件**
2. 选文件，或直接把文件拖进 Canva 窗口
3. 上传完点一下就插入到画布

建议在 Canva 里建一个文件夹叫「圣合丰 LOGO」，把这些都放进去，以后每个设计都能直接调用。

## 注意事项

- PNG 都是**透明底**（除了 `-whitebg` 那个）。放在深色背景上也不会有白框。
- 所有图长边 3000px，够做 A3 尺寸印刷，文件都在 1.3MB 以内，Canva 上传限制是 25MB，不会超。
- **不要在 Canva 里拉伸变形**。缩放时按住角上的圆点等比缩放，不要拖边上的方点。
- 最小使用尺寸建议 **宽度不小于 25mm / 110px**。再小木纹会看不清，这时候换用单色版。
- Logo 四周请留出至少「一个木脚宽度」的空白，不要贴边或压图。

## 品牌色（Canva 里可以存成品牌色板）

| 用途 | 色值 |
|---|---|
| 字标棕（主色） | `#3F1A08` |
| 木色高光 | `#AE7A44` |
| 木色中间调 | `#9C6733` |
| 木色暗部 | `#452409` |
| 文字黑 | `#111111` |
| 深底反白用米色 | `#F5EFE6` |
