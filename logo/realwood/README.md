# 真实木纹版 logo

木脚换成照片级的真实木纹，其余部分不变：字标、书法、英文全部保持矢量。

## 木纹怎么来的

木纹是**程序模拟**的，没用网上的木纹照片，所以不存在图片版权问题。模拟过程按真实工艺来：

- 一根实木毛料，年轮绕着毛料外的树心，纹理略微斜走
- 车成锥形脚以后，刀面切过年轮，自然出现**山形纹**（大教堂纹）
- 早材颜色浅、晚材颜色深，年轮宽窄不一，纹理顺着木头长度方向流动
- 表面有细长的**导管纹**，实木的特征
- 光照按车削轮廓计算，所以**凸环、倒角、脚圈都有真实的明暗**，另外加了一道亮光漆面的高光

## 黑白版

真实木纹有两种黑白做法，用途不一样：

| 文件 | 是什么 | 用在哪 |
|---|---|---|
| `shenghefeng-logo-realwood-gray-compact.png` / `-gray.png` / `shenghefeng-horizontal-realwood-gray.png` | **灰度版**：照片木纹去色，像黑白照片 | 黑白打印、黑白报纸广告、单色目录、复印件 |
| `shenghefeng-logo-realwood-bw-compact` / `-bw` / `shenghefeng-mark-realwood-bw` / `shenghefeng-horizontal-realwood-bw` | **纯黑白版**：只有黑和白，木刻版画风格 | 丝印、烫金、激光雕刻、印章、纸箱印刷、刺绣制版 |
| 上面纯黑白版文件名带 `-white` 的 | 纯黑白版的反白版 | 深色背景、黑色包装、深色木头上激光雕刻 |

两个黑白版都是**平面**的，没有光影明暗：没有受光面、背光面，没有高光，整根木脚是一个均匀的色调，只有木纹在变化。

- 灰度版：均匀的平面灰色木纹，车削槽是细深色线。
- 纯黑白版：黑色木脚上是**等宽**的白色木纹线，每条线一样粗。顶块、凸环和脚圈是实心黑，只用等宽白线勾出车削槽，木纹留在锥形主体上。

纯黑白版是**真矢量 SVG**，整个 logo 只有一个颜色，木纹是镂空：
- 发给印刷厂、雕刻厂可以直接开版
- Canva Pro 导入后点一下就能整体换成任意颜色（比如烫金色）
- 太细、印不出来的木纹线已经自动去掉

小尺寸提醒：纯黑白版木纹线比较细，**宽度建议不小于 30mm**。更小的场合用 `../canva/logo-black-compact` 那种线条单色版。

## 什么时候用真实木纹版，什么时候用线条版

| 场合 | 用哪版 |
|---|---|
| 网站、电商主图、产品目录、展会海报、朋友圈、视频片头 | **真实木纹版**，彩色屏幕和彩色印刷上最有质感 |
| 名片、信纸这类小尺寸彩印 | 两版都行，宽度 25mm 以下建议线条版 |
| 丝印、烫金、刺绣、激光雕刻、纸箱印刷 | **纯黑白版**（`-bw`），或者线条单色版 |
| 黑白打印、复印、传真 | **灰度版**（`-gray`） |
| 极小尺寸，如图标、印章 | 单色版 |

## 重新生成

```bash
python3 ../build_realwood.py      # 彩色
python3 ../build_realwood_bw.py   # 灰度 + 纯黑白
```

想换木种颜色，改脚本开头的 `EARLY`（早材，浅色）和 `LATE`（晚材，深色）两个颜色。
