# 圣合丰 商标定稿版

在已认可的平面纯黑白版基础上，按商标标准做的优化。

## 设计上改了什么

| 问题 | 优化 |
|---|---|
| 白线粗细不一，最细的车削槽线 20mm 以下就消失 | **全标只用一种线宽**，木纹线、车削槽、接缝都一样粗，20mm 时仍然清楚 |
| 木纹有断头、碎片，随机感重 | 重画成等粗的火焰拱纹，线条连续，数量更少更疏，缩小不粘连 |
| 木纹贴着轮廓边缘，小尺寸时轮廓破碎 | 木脚内侧留一圈实心黑边，**轮廓永远完整** |
| SHENGHEFENG 下方一排碎竖齿（原金属脚留下的残笔） | 收成实心颈部，木脚和框架之间加一道干净接缝，像木脚安装在沙发框架下 |
| 字母上方细横条和字母之间几乎没缝 | 横条上移，拉开间隙 |
| 字母内部白缝窄，缩小时糊成一块 | 字母内白缝略微加宽 |
| 英文标语是从 9 像素小字描出来的，边缘发毛 | 用正规字体重排，字宽、字距和原来一致 |

`small-size-test.png` 模拟了印刷和烙印的油墨扩散，比较原版和优化版在 15 / 20 / 30mm 宽时的效果。

## 商标注册建议

以下是设计角度的常见注意事项，**不是法律意见**。提交前请让商标代理人做一次近似检索并确认。

1. **注册版去掉 "CHINA / WORLDWIDE SUPPLY"**。商标法第十条禁止使用与中华人民共和国国家名称相同或近似的标志，含 "CHINA" 或 "中国" 的商标通常会被驳回。这一行可以在包装和宣传上照常用，不要放进注册图样。
2. **注册版去掉 "SOFA WOODEN LEGS"**。它直接描述商品本身（沙发木脚），属于描述性文字，注册了也不能独占，还可能增加审查麻烦。日常使用版保留。
3. **用黑白图样申请**。黑白注册以后，使用时可以换成任何颜色，包括棕色木纹版、烫金版；如果用彩色申请，保护范围会被限定在那个颜色上。
4. **建议分开申请，组合保护**：
   - 文字「圣合丰」（标准字体）
   - 图形（`-graphic` 那张，木脚 + SHENGHEFENG）
   - 组合（`filing` 那张）

   分开注册的好处是：以后单独用文字或单独用图形都受保护，其中一件被驳回也不影响另外几件。
5. **类别**。木制沙发脚一般在第 20 类（家具、非金属家具配件），具体小项让代理人按你们的产品范围选；如果以后也做金属脚，再考虑第 6 类。
6. **确认字体和书法的版权**。
   - 「圣合丰」三个字如果来自商用书法字体，比如方正或汉仪的字库，需要买商业授权，否则有被字库公司起诉的风险。
   - 如果是请人写的，最好拿到书面授权。
   - SHENGHEFENG 弧形字是最初 logo 设计师做的，同样建议拿一份著作权转让或授权书。
7. **® 和 ™**。注册下来之前可以在 logo 右上角标 ™，**拿到注册证之后才能用 ®**，提前用 ® 属于违法。

## 使用规范

- **最小尺寸**：图形宽度不小于 **20mm**。SHENGHEFENG 字母清晰辨认需要 **30mm** 以上；更小的地方，比如木脚底部的烙印或小吊牌，可以只用图形，或者只用「圣合丰」三个字。
- **安全空间**：logo 四周留出至少一个木脚顶块宽度的空白。
- **颜色**：标准为纯黑或纯白；也可以用品牌棕 `#3F1A08` 或烫金，但不要加渐变、阴影、描边。
- **不要**拉伸变形，不要改字距，不要把木纹换成其他图案。
